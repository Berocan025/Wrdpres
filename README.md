# 🔑 WooCommerce Otomatik Lisans Teslimatı - BERAT K Geliştirme v2.1.0

Modern, güvenli ve şık lisans anahtarı teslim sistemi. WooCommerce siparişleri tamamlandığında otomatik olarak lisans anahtarları müşterilere gönderilir.

## ✨ Yeni Özellikler (v2.1.0)

### 🎯 **Akıllı Pending Sistemi**
- Admin panelinden key eklenen ürünler bittiğinde müşteriler otomatik olarak bekleme listesine alınır
- "24 saat içinde keyiniz hazırlanacaktır" e-postası otomatik gönderilir
- Admin key eklediğinde bekleyen müşterilere otomatik teslimat

### ⏰ **24 Saatlik Bekleme Animasyonu**
- Müşteri panelinde key yokken güzel bir saat animasyonu
- Shimmer efekti ile modern görünüm
- Pulse animasyonu ile dikkat çekici tasarım

### 📱 **Mobil Responsive Tasarım**
- Tüm cihazlarda mükemmel görünüm
- Kartlar ve animasyonlar mobilde optimize edildi
- Modern gradient tasarım ve smooth geçişler

### 📋 **Geliştirilmiş Kopyalama**
- Tek tıkla kopyalama özelliği
- Başarı animasyonları ve toast bildirimleri
- Key highlight efektleri
- Fallback için eski tarayıcı desteği

### 🔄 **Otomatik Güncelleme**
- Pending durumundaki müşteriler için otomatik kontrol
- Key hazır olduğunda sayfa otomatik yenilenir
- Real-time AJAX güncellemeler

## 📦 Kurulum

1. `woocommerce-otomatik-lisans-teslimat-berat-k-v2-updated.zip` dosyasını indirin
2. WordPress admin panelinde **Eklentiler > Yeni Ekle > Eklenti Yükle** kısmından ZIP dosyasını yükleyin
3. Eklentiyi etkinleştirin
4. **WooCommerce** eklentisinin kurulu ve aktif olduğundan emin olun

## ⚙️ Kullanım

### 1. Ürün Ayarları
- Ürün düzenleme sayfasında **Genel** sekmesinde lisans anahtarları alanını bulun
- Her satıra bir lisans anahtarı girin
- Ürünü kaydedin

### 2. Admin Paneli
- **Lisans Anahtarları** menüsünden eklentiye erişin
- İstatistikleri görüntüleyin
- Bekleyen müşterileri yönetin
- Toplu lisans anahtarı ekleyin

### 3. Müşteri Deneyimi
- Müşteriler **Hesabım > Lisans Anahtarlarım** kısmından anahtarlarına erişir
- Key yoksa 24 saatlik bekleme animasyonu görür
- Key hazır olduğunda otomatik güncelleme alır
- Tek tıkla kopyalama özelliği
